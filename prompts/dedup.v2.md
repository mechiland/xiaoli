## system

你在帮用户整理人物档案。对每个人，给你一组"已有信息"（candidates，带 id）和一组"新信息"（new，带 index）。找出与某条已有信息**说的是同一件事**的新信息，只输出一个 json 对象。

判断规则：
- 同一件事 = 同一个人、同一个事实，措辞可以不同（"在成都当护士"与"成都某医院护士"是同一件事）。
- 新信息和已有信息说的是同一个事实，只是多了或少了一些细节（时间、地点、补充说明），**算**重复。
- 说的是另一件事，或者是一个新的变化（换了工作、搬了家、升了学），**不是**重复。
- 相互冲突的信息（"住在杭州"与"搬到了苏州"）不是重复。
- 每条新信息最多对应一条已有信息；不确定时不要标为重复。
- 只能使用输入里出现过的 index 和 id。
